# Motion Canvas

Create a premium personal portfolio website for a VIDEO EDITOR & VISUAL DESIGNER.

IMPORTANT:

Use the attached reference image as the primary visual/layout inspiration.

The website should NOT look like a generic portfolio template.

It should feel like a high-end creative director / video editor portfolio, with the visual identity centered around MOVING VIDEO, EDITING, MOTION DESIGN, and CINEMATIC PRESENTATION.

The key visual idea from the reference is extremely important:

A large rounded rectangular panel/card sits in the center as the main focal point.

Around the central panel are multiple video/image panels arranged horizontally. These surrounding panels should continuously move in a seamless horizontal loop, creating the feeling of an infinite cinematic reel.

The surrounding panels should:

- Move continuously from left to right / right to left

- Loop infinitely without a visible reset

- Have different sizes and depths

- Become smaller and slightly blurred toward the edges

- Become sharper and larger closer to the center

- Slightly overlap each other

- Use subtle perspective and rotation

- Feel like video frames floating around the main content

- Extend beyond the viewport so the page never feels like a normal carousel

The center panel remains fixed and dominant.

The overall composition should feel like a sophisticated motion-design installation rather than a conventional website.

==================================================

INFINITE VIDEO REEL

==================================================

This is one of the most important components.

Create an infinite horizontal video gallery.

Use multiple video cards with rounded corners.

Example arrangement:

        [VIDEO] [VIDEO]

   [VIDEO] [ MAIN VIDEO ] [VIDEO]

        [VIDEO] [VIDEO]

But implement the movement horizontally rather than as a static grid.

The center video should remain visually dominant.

The surrounding videos should continuously move behind it.

Create depth using:

- scale

- opacity

- blur

- translate

- rotation

- perspective

The animation must be seamless.

Duplicate the video sequence if necessary so the loop never visibly resets.

Use transform-based animation for performance.

The video cards should feel like an actual editing reel.

On hover:

- Slight scale increase

- Sharpen the video

- Increase opacity

- Show project title

- Show category

- Add a subtle play icon

==================================================

ANIMATION SYSTEM

==================================================

Animation is a core part of the website.

Use Framer Motion / Motion.

Use:

- Scroll-triggered reveals

- Smooth horizontal movement

- Infinite marquee

- Infinite video carousel

- Parallax

- Scale

- Opacity

- Blur

- Clip-path reveals

- Spring animations

- Hover interactions

- Magnetic buttons

- Cursor interactions

Animations should feel intentional and premium.

Do not make every element bounce or animate excessively.

Use short, smooth transitions.

==================================================

VIDEO CARD BEHAVIOR

==================================================

Video cards are the heart of the design.

Where possible, use actual HTML5 video elements.

Videos should:

- autoplay when appropriate

- be muted

- loop

- use object-fit: cover

- preload intelligently

- pause when no longer needed

If actual video assets are unavailable, create visually convincing video placeholders that can easily be replaced with MP4/WebM files later.

Do not use random unrelated stock images as the final design.

==================================================

RESPONSIVE DESIGN

==================================================

Desktop:

The cinematic infinite video system is fully visible.

Use a large central video card with surrounding moving panels.

Tablet:

Reduce the number of visible surrounding panels while maintaining the central composition.

Mobile:

Keep the central video as the main focal point.

Transform the surrounding video system into a tighter horizontal scrolling reel.

Do not allow horizontal page overflow.

The mobile version should still feel animated and cinematic.

Navigation becomes a fullscreen menu.
